# eager-tuner-mini

TypeScript · Terraform · Linux

学习用的示例项目

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/eager-tuner-mini.git
cd eager-tuner-mini
chmod +x run.sh
```
